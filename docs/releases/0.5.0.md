# CYDpod 0.5

Released 7 November 2026 for the JC2432W328C. The owner reported overnight shuffle playback with the audio still fine and selected this build as the 0.5 baseline. The receiver in the preceding playback tests was a JBL Flip 3 with a 1,477-track SD library.

The firmware combines batched PCM transfers, producer wakeups, a 4,096-frame ring, the optimized compact FLAC decoder, and Classic list flick changes. Moving lists draw title bands at up to 30 Hz, prefetch names when the audio buffer has room, and start the coast after a confirmed lift. A contact catches the coast without selecting a song.

The release preserves the exact firmware compiled from `1cc1b4dc142506378cf2e2f0191145b80103918f`. The `v0.5.0` source adds release documentation and the local release ignore rule. Firmware, decoder sources, dependency pins and build flags match that compiled revision. The Bluetooth application SHA256 is `4e5d41fb7ac1139e27b7ccba9224e79e89db8c0e3727b53db759191aebf5386d`.

Existing CST820, touch, scroll-core and Classic UI checks passed. Both W328C variants compiled, and a fresh checkout rebuilt using the archived Windows toolchain. Original flash regions, debug symbols and manifests are retained. A fresh build can produce a different application hash. Use the released binaries for an exact restore.

The overnight report is a listening result. It does not record a duration, missing-frame counters, or the timed portrait and landscape scrolling comparison. Those measurements remain in the [board comparison procedure](../research/flick-motion.md).

Download the firmware, offline build kit, source, debug symbols and enclosure files from [GitHub Releases](https://github.com/nlpeeee/CYDpod/releases/tag/v0.5.0). The repository is private during the initial migration. Enclosure v4 is an editable prototype awaiting a physical fit trial.
