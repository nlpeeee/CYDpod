# CYDpod 0.5.1

Released 7 November 2026 for the JC2432W328C. This consolidates the Bluetooth and Now Playing candidates onto the 0.5 compact-FLAC / 4,096-frame PCM / flick-scrolling baseline.

Changes since 0.5.0:

- Upgrade ESP32-A2DP to pinned 1.8.12 while retaining the internal SBC callback, codecs, PCM ring and core assignments.
- Reduce Bluetooth menu refreshes and discovery/RSSI updates; stop idle control polling and bound inquiry cleanup.
- Add device-specific Connect, Disconnect and confirmed Forget actions. Disconnect pauses playback and retains pairing.
- Fix list-scrollbar painting erasing the right side of Now Playing and its Repeat control.
- Mirror supported speaker volume reports in Now Playing. Local controls use the same absolute volume, with command coalescing and no notification echoes or duplicate gain. Headphones and unsupported receivers retain software volume; sleep fading remains active.
- Establish initial volume on connect/reconnect when no initial report arrives, using CYDpod's current volume and the speaker's confirmed response. Preserve newer slider changes through that confirmation.

The release keeps the exact final candidate firmware compiled from `ad3f72b13466a9e7e23a3babf20397e76ee0d19c`. `v0.5.1` identifies matching source plus release documentation and build-kit helpers. Flash binaries, manifests, source, offline Windows build kit, debug symbols, enclosure v4 and checksums are separate downloads. Use the released binaries for an exact restore; rebuilt application hashes can differ.

PASS evidence covers Bluetooth pairing/reconnect/media policies, Classic UI and the Now Playing pixel regression, focused absolute-volume/initial-handshake tests, actual PCM gain/fade/fallback checks, and both W328C compile variants. Static RAM is 87,240 bytes for Bluetooth and 87,248 bytes for wired, 552 bytes above 0.5.0. Existing check logs are retained; firmware was not changed or rebuilt solely for the version number.

The owner reported that the Now Playing redraw fix was much better and that volume feedback worked after a speaker-button change, then requested 0.5.1 promotion following the initial-sync fix. This is owner approval to release, not a new timed playback or reconnect trace. The original 0.5 overnight shuffle report remains the long-run baseline. Full receiver-specific playback/memory measurements, actual AirPods Pro 2, wired hardware and enclosure fit qualification remain open. Earlier JBL breakup/paused-noise reports have no matched diagnostic capture establishing a complete resolution.

Bluetooth volume now follows the speaker's own scale, so percentages can sound different from 0.5.0. Begin the first comparison at low speaker volume. Flash the four matching regions to preserve settings and pairings, then verify. Instructions are in the firmware archive README. The offline build kit uses the previously verified base toolchain plus a hash-checked 1.8.12 library overlay.
