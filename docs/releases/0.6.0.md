# CYDpod 0.6.0

Released 9 November 2026 for two boards: the **JC2432W328C** (capacitive touch) and the generic **ESP32-2432S028R** (resistive touch). 0.6.0 adds a queue you can build as you go (Up Next), gapless playback and a brighter startup screen. It also makes the resistive board an official release target.

## Changes since 0.5.5

**Up Next**
- **Hold to queue:** hold a song, album or artist for about half a second and choose **Play next** or **Add to queue**.
  - It works on any song row: Songs, an album's or artist's songs, search results, folders, playlists and Favourites.
  - An album queues all of its songs, and an artist queues all of theirs.
- **Order:** queued songs play before the rest of the list, then the list carries on from where it was.
- **Up Next page:** Now Playing → Options → **Up Next** shows the queue.
  - Tap a song to play it now.
  - Hold a song to play it now or remove it.
  - **Clear Up Next** empties the queue.
- **Size and lifetime:** the queue holds 64 songs. It is kept through screen-off and Sleep, and cleared by a restart.
- A short tap still plays the song, as before.
- Details: `docs/specs/up-next-and-gapless.md`.

**Gapless playback**
- **No more pause between tracks.** The next song is opened while the last ~139 ms of the current one is still playing, so continuous albums run straight on.
- **MP3:** files no longer start with a 26 ms frame of silence. The encoder's padding at each end is now trimmed for MP3s that carry a LAME or FFmpeg tag. Seeking and the time shown follow the trimmed length.
- **AAC, FLAC and WAV** were already trimmed or have no padding.
- Skips, seeks and picking a song still change track at once.
- **Paused at the end** of a song, the player stays on that song until you press Play.
- **Serial:**
  - `stat: gap track N missing F frames` follows every track change; 0 means gapless.
  - `gapless on|off` switches it for comparison.

**Startup screen**
- The splash yellow is now a saturated `#FFC800`. The old `#FFD21F` looked pale on the panel, as if the screen were faulty.
- The text and the progress bar keep their colours.

**Two boards, one release**
- **JC2432W328C:** `CYDpod-0.6.0-firmware.zip`. One image plays over Bluetooth or a wired I2S DAC (Settings → Audio Output → Headphones). The separate wired-only image is retired, after the owner confirmed wired output on 0.5.5's main build.
- **ESP32-2432S028R:** `CYDpod-0.6.0-firmware-ESP32-2432S028R.zip`. It plays over Bluetooth or the board's speaker pad, and drives both ILI9341 and ST7789 glass.
- **Build options:** `tools/check.ps1 -Board esp32-2432s028r` builds the resistive image, alongside `-Board jc2432w328c`.
- **Manifests:** each board's `MANIFEST.json` names the board and lists only flashable files.
- **Packaging:** `tools/release/Package-Release.ps1` assembles the release folder and the GitHub assets for both boards. It reuses the previous build kit only when `dependencies.lock.json` is unchanged.

## Provenance

- **Firmware commit:** both images were compiled from the commit tagged `v0.6.0`. `RELEASE.json` and each `MANIFEST.json` record its hash.
- **Toolchain:** the build inputs are unchanged since 0.5.5: the same `dependencies.lock.json`, the trimmed Bluedroid with patches 0001–0003, and the 0.5.4 toolchain and A2DP overlay. The build kit is 0.5.5's, renamed.
- **Version label:** `FIRMWARE_VERSION`, the label on the splash screen, remains `1.2.0`.

## Checks

- **Host:**
  - audio order suite PASS (Up Next ordering and gapless clock);
  - codec pool suite PASS (all 36 MP3 fixtures bit-exact with stock Helix on the gapless window; WAV/MP3 seek; a real-decoder gapless boundary with 0 missing frames and 0 underruns);
  - UI and catalogue suites PASS for both the Bluetooth and the wired builds (hold menu, Up Next page, reachable pages, layout golden unchanged);
  - splash test PASS (`0xFE40` background, progress track unchanged).
- **Release compile:** `tools/check.ps1 -SkipProbe -SkipHostMedia -LargePcmRing -PcmRingFrames 6144 -BuildLabel release-060` PASS for each board:

  | Board | Flash | Static RAM | Change since 0.5.5 |
  | --- | --- | --- | --- |
  | JC2432W328C | 1,333,825 B | 81,148 B | +296 B RAM |
  | ESP32-2432S028R | 1,277,153 B | 78,924 B | +296 B RAM |

- **Boot files:** the bootloader, partition table and `boot_app0.bin` are byte-identical to 0.5.5 on both boards.
- Evidence: `docs/research/up-next-and-gapless.md`.

## Not yet confirmed on hardware

- **Not board-run:** neither 0.6.0 image has been run on a board as a whole. The ESP32-2432S028R image has never been board-run, in 0.5.5 or now.
- **Gapless on the board:** it depends on the SD card opening the next file within the ~139 ms buffer. `stat: gap` reports any shortfall.
- **The hold menu** on the capacitive (CST820) and resistive (XPT2046) panels.
- **Up Next after Sleep:** that the queue survives Sleep.
- **Splash colour** on both panel types.
- **Still open from 0.5.5:**
  - FreeBuds Pro dropping the link soon after the stream starts;
  - one AirPods silence after a mid-stream rate step;
  - slow long seeks in MP3 files;
  - the +6 dBm transmit power reading back +3 dBm at startup;
  - the touch interrupt;
  - the ~4 s wake-to-sound target;
  - enclosure fit.

## Flashing

- **From 0.5.2 or later:** flashing `app.ino.bin` at `0x10000` is enough on either board. Otherwise flash all four regions.
- **What's kept:** settings and pairings are kept either way.
- **Folders:** each board's files are in `firmware/<board>/` (`firmware/jc2432w328c`, `firmware/esp32-2432s028r`). Instructions are in the zip's README and in `docs/firmware/README.md`.
