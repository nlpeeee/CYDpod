# CY-116B: bounded audio order

Implementation: `1f5e821` (final amend adds this report only), base `df00193`.

- Replaced the uint16 order allocation with a six-round seeded Feistel
  bijection, cycle-walked over queue positions. Forward/inverse lookup needs
  no per-track storage. An output swap puts the selected queue entry first.
- Queue identity, array and callback sources remain supported; SD errors stop
  playback without publishing an invalid request. Duplicate queue entries
  remain separate positions. Queue changes/shuffle toggles reseed.
- Repeat One and Off retain their existing actions. Repeat All wraps the same
  permutation, preserving next/previous round trips across the boundary;
  it no longer draws a fresh shuffle at each wrap.
- Resident order state is 28 B at every N (host sizeof and ESP32 ELF size 0x1c); the previous heap
  allocation was 4,000 B at 2,000 and 20,000 B at 10,000 tracks. Zero growth
  with N; net static increase is 24 B over the ESP32 pointer it replaces.
